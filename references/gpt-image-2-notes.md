# GPT-image-2 官方特性摘要

来源（2026-08-22 核验）：

- OpenAI Developers: [GPT Image Generation Models Prompting Guide](https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide)（2026-04-21）。
- OpenAI Developers: [GPT Image 2 model](https://developers.openai.com/api/docs/models/gpt-image-2)。
- OpenAI Developers: [Image generation guide](https://developers.openai.com/api/docs/guides/image-generation)。

## 能力重点

- 适合生产级视觉、可控创意工作流、专业设计任务和迭代式内容创作。
- 适合高质量摄影感、自然光照、材料质感、复杂结构图、信息图、多面板构图、可靠图中文字、角色一致性、图片编辑和多图合成。
- `gpt-image-2` 是新工作流的默认选择；旧模型主要用于已验证流程的兼容期。
- `low` 适合速度和成本优先的探索；`medium`/`high` 适合小字、信息密度、身份保留、近景和客户可见资产。
- 支持灵活尺寸、透明背景 PNG/WebP（预览）和高保真图像输入；透明素材可直接用于 logo、商品抠图、贴纸和演示组件。
- 它的图像生成与编辑可通过 Image API 完成；需要对话上下文和多轮高保真编辑时，可使用 Responses API 的图像生成工具。

## 这次更新需要改变的提示词策略

- **透明底不再默认先出白底再去背**：需要隔离素材时，建议 `background="transparent"` + `output_format="png"` 或 `"webp"`。提示词写明完全透明背景、不要布景/实底/棋盘格/多余阴影；PNG 不传 `output_compression`，JPEG 不支持透明。
- **结构化成品可以直接写成“成品规格”**：最终海报、信息图、图解、图表和幻灯片图片，应直接说明成品类型、画布、信息层级、真实文字/数据、阅读顺序、留白与禁止项；小字、图例、坐标轴和脚注优先 `quality="high"`。如果内容仍需频繁修改，则保留在可编辑层。
- **编辑保真不依赖 `input_fidelity`**：`gpt-image-2` 的 `input_fidelity` 被禁用且不生效。改用“只改变 X、其余不变”+ 明确保留身份/几何/相机/光线/布局 + 图片索引 + 单点迭代。
- **能力变强不等于删除约束**：文字、人物动作、真实感、多图合成和风格迁移仍要写清具体对象、位置、姿态、材质、禁止项和不变项；不要只写“高质量”或“像参考图”。

## 尺寸边界

`gpt-image-2` 支持满足以下条件的自定义 `size`：

- 长边小于 `3840px`。
- 两条边都是 `16` 的倍数。
- 长边与短边比例不超过 `3:1`。
- 总像素不少于 `655360`，不超过 `8294400`。
- 超过 `2560x1440` 时结果可能更不稳定，先把它当作实验尺寸。

常用尺寸：

- 方图：`1024x1024`
- 横图：`1536x1024`
- 竖图：`1024x1536`
- 16:9：`2560x1440`

## 透明输出与参数边界

- 默认不需要显式传 `background`。透明资产才传 `background="transparent"`。
- 透明输出用 `output_format="png"`（默认）或 `"webp"`；PNG 不传 `output_compression`，WebP 可按交付体积需要设置压缩。
- `gpt-image-2` 不使用 `input_fidelity`。不要从旧模型工作流复制该参数。

## 提示词基本法

- 用稳定顺序写：背景/场景 -> 主体 -> 关键细节 -> 约束。
- 复杂需求用短段落和标签，不写成一整段长句。
- 说明用途：广告、UI mock、信息图、产品目录图、课程配图、桌游样卡等。
- 描述构图：远近、视角、主体位置、留白、光线和情绪。
- 需要真实照片时写明 `photorealistic`、真实纹理、自然瑕疵和摄影构图。
- 编辑图片时写“只改变 X，保留 Y”，并在每次迭代重申保留项。
- 多图输入时按 `Image 1`、`Image 2` 说明每张图的角色和互动方式。
- 先建立干净基础提示词，再用单点 follow-up 迭代。

## 输出时必须转写成规则项

写给用户的最终提示词中必须包含 `GPT-image-2 rules:` 段落。它的作用是把模型特性变成可执行约束，而不是停留在外部说明。

默认中文输出：除 API 参数、`GPT-image-2 rules:`、`Image 1/2/3`、`EXACT, verbatim, no extra characters` 这类必要控制词外，提示词字段、规则、检查点和迭代指令都写中文。用户明确要求英文时再切换。

按任务选择：

- 真实摄影/产品图：photorealistic、自然光照、真实材质、接触阴影、边缘质量、标签可读。
- 信息图/教学图：结构化布局、分区、层级、阅读顺序、文字短且高对比。
- 卡牌/包装/印刷：比例、出血、安全边距、纸张/油墨/烫金/边缘、广告留白、文字可编辑层。
- 角色/人物：身份、脸部、服装、比例、姿态、视线和动作几何一致。
- 编辑任务：只改变指定对象，保留相机角度、布局、光照、阴影、周围物体和主体身份。
- 多图合成：每张输入图按索引说明角色，不让风格参考覆盖主体识别。
- 去 AI 感质感控制：干净商业视觉、插图、Logo、产品图、样卡和课程图可加入柔和漫射光、真实平滑阴影、清晰不过锐边缘、干净色彩过渡、平衡对比度和克制细节；避免油腻高光、塑料质感、噪点颗粒、脏污纹理、浑浊色彩、斑驳阴影、混乱细节和过度渲染。
- PSD/分层拆分友好：官方图像接口输出的是 PNG/JPEG/WebP 等图像格式，不是 PSD 分层源文件；用户要 PSD、图层、分拆、矢量、素材包时，应生成适合后期拆层的视觉稿、透明素材、元素平铺图和图层清单。
- 透明素材：主体独立、完全透明背景、无场景/实底/棋盘格/粘连阴影；下游保存与转码时保留 alpha 通道。
- 含文字营销图：精确文案加引号，要求原样渲染、只出现一次、清晰可读。
- 最终信息图/图解/幻灯片图片：按成品规格直接给出确认后的文字、数字和层级；要求高可读性、整洁间距与无装饰干扰，并在生成后核对每项文字和数据。

## 易错点诊断

- **主体漂移**：增加身份/几何/品牌/布局保留项。
- **局部编辑影响全图**：加入 `change only... keep everything else unchanged`，并列出不要改的项目。
- **画面太复杂**：删元素，减少风格词，增加留白和主体层级。
- **AI 感太强**：加入质感控制块，降低油腻高光、塑料质感、过锐边缘、过强对比、浑浊色彩和混乱细节；但纪实/胶片/旧物风格不要误删必要颗粒和瑕疵。
- **误以为能直接输出 PSD**：说明模型生成图像文件，不直接生成 PSD 图层；改为输出 PSD 拆分友好提示词、图层命名清单、透明 PNG 素材建议和后期制作步骤。
- **文字错误**：缩短文案，放入引号，要求 verbatim，指定只出现一次，提高 quality。
- **中文长文案不稳**：把正文放回可编辑层，只在图中放短标题或视觉化关键词。
- **透明素材出现底色或粘连阴影**：核对 `background="transparent"`、PNG/WebP 输出和“主体独立”限制；仍不稳定时，再建议白底图与下游去背。
- **把旧模型参数复制给 GPT Image 2**：删除 `input_fidelity`，改为清晰的保留项和单点编辑迭代。
