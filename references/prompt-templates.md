# GPT-image-2 中文提示词模板

所有模板默认输出中文。生成实际提示词时，字段名、规则解释、检查点和迭代指令都用中文；只保留必要英文控制词：`GPT-image-2 rules:`、`EXACT, verbatim, no extra characters`、`Image 1/2/3`、API 参数名。所有模板都要保留 `GPT-image-2 rules:` 段落，替换成和任务相关的 3-8 条中文规则；不要删除该段。

需要干净、商业级、插图、Logo、产品图、样卡或用户要求“去 AI 感”时，在模板中加入：

```text
质感控制：
自然干净的画面，柔和漫射光，真实平滑的阴影，清晰但不过度锐化的边缘，干净色彩过渡，平衡对比度，细节克制有层次。避免油腻高光、塑料质感、噪点颗粒、脏污纹理、浑浊色彩、斑驳阴影、混乱细节和过度渲染。
```

【摄影/插画/3D/印刷/编辑风格，真实材质、光线、色彩、质感。】

【按需加入去 AI 感质感控制块；若目标是胶片、纪实、粗粝或脏旧风格，可改写或省略。】

GPT-image-2 rules:
- 使用生产级构图，层级清楚，焦点可读，主体和辅助信息不互相抢占。

- 保持提示词可控：不要无关物件，不要风格漂移，不要不必要的视觉堆叠。

## PSD/分层拆分友好设计稿

```text
为【使用场景】创建一张适合后期制作 PSD 分层文件的设计稿视觉预览。

重要边界：
GPT-image-2 只生成视觉稿或素材图，不直接输出真正的 PSD 图层源文件。请把画面设计成便于后期在 Photoshop/Figma 中拆层、抠图、矢量重绘和重新排版的结构。

目标：
【说明这张设计稿最终用于海报、电商主图、详情页、社媒图、包装视觉、活动页或品牌物料。】

画面主体：
【主体是谁/是什么，主体和辅助元素的关系。】

场景与构图：
【画幅比例、版式分区、主体位置、背景区域、装饰区域、文字占位区域和留白。】

PSD/分层拆分规则：
- 背景、主视觉、产品/角色、装饰元素、图标、标签、按钮/文字占位、阴影高光、纹理各自清楚分区。
- 每个素材边缘清晰、无遮挡、少重叠，便于后期抠图、分拆为透明 PNG 或重绘为 SVG/矢量。
- 文字、价格、参数和按钮文案只保留为空白占位区域，不生成正式文字。
- 阴影和高光不要和主体粘死，保持可拆分、可单独调整的视觉关系。
- 装饰元素尽量独立散布，不要压住主体和文字占位区。

建议图层清单：
- 背景层：纯色/渐变/场景底图。
- 主体层：产品、角色或核心视觉。
- 装饰层：光效、图案、符号、贴纸、小元素。
- 信息层：标题区、卖点区、按钮区、参数区的空白占位。
- 效果层：阴影、高光、质感纹理，可后期单独调整。

质感控制：
自然干净的画面，柔和漫射光，真实平滑的阴影，清晰但不过度锐化的边缘，干净色彩过渡，平衡对比度，细节克制有层次。避免油腻高光、塑料质感、噪点颗粒、脏污纹理、浑浊色彩、斑驳阴影、混乱细节和过度渲染。

GPT-image-2 rules:
- 以“后期可拆层”为核心目标，不要把所有元素融合成不可分割的一张复杂插画。
- 保持主体、背景、装饰和信息占位之间的边界清楚。
- 需要透明素材时，建议另行生成单个元素的透明 PNG 版本。
- 不要生成正式文字、水印、随机 logo、价格、促销词或无法编辑的小字。

文字要求：
图片内不要正式文字，只保留干净的空白文字占位区域。

限制条件：
不要把主体和背景粘连。
不要让装饰元素遮挡主体。
不要生成大段文字。
不要生成不可拆分的复杂合成光效。
```

## PSD 素材包拆分生成

```text
请把同一个设计方向拆成 5 张独立素材图，便于后期制作 PSD：

1. 完整效果预览图：展示最终构图和整体氛围。
2. 背景空版图：只保留背景、光影和场景，不要主体、文字和装饰。
3. 主体透明素材图：只生成主体，背景透明或纯白，边缘清晰，无阴影粘连。
4. 装饰元素平铺图：把图标、贴纸、符号、纹理小元素分散平铺在干净背景上，彼此不重叠。
5. 文字占位版式图：只展示标题区、卖点区、按钮区、参数区的空白框架，不生成正式文字。

GPT-image-2 rules:
- 每张素材图都必须能单独用于后期拆层。
- 主体、装饰、背景和文字占位不要混在一起。
- 输出优先 PNG；需要透明底的素材使用透明背景或纯白背景便于抠图。
- 所有元素保持同一视觉风格、同一色彩体系和同一构图逻辑。
```
